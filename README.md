# About

This repository contains various mini-projects I have worked on.

## List of projects

### 1. Project 1
Jupyter Notebook notes on the basics of Python for high school students, including demonstrations.  
The exercises focus mainly on physics problems that require the use of numerical methods.

### 2. Project 2
This project contains two modules:

1. The first module builds an Excel table based on a list of students’ names and the number of tests to be taken during the semester.  
2. The second module reads the Excel table and randomly selects students to take a test, ensuring that no student exceeds their assigned number of tests.

### 3. Project 3

This project includes a Python package `numerical_methods` which provides:
1. Methods to solve scalar equations (equations of one variable)
2. Methods to solve differential equations of the type dy/dx = f(x, y) for given initial data (x0, y0) and function f

Jupyter notebooks with examples demonstrating how to apply these numerical methods are included.

### 4. Project 4
A simple arcade-style space game built with the `pygame` library, using object-oriented programming principles and a small SQL database.
