# Equation Solver

This is a small Python package that provides simple numerical methods for solving equations.

## Features

1. **Scalar equations** — functions to find roots of equations with one variable.
2. **Differential equations** — solvers for initial value problems of the form  
   dy/dx = f(x, y), including:
   - Explicit Euler method
   - Runge–Kutta 4th order method
