# Simple Arcade Space Game

This is a small arcade-style space shooter I am building for fun and learning.  
The project uses clean object-oriented structure and is built on the `pygame` library.

## Features
- Player movement and shooting  
- Multiple enemies  
- Score tracking  
- Persistent highscore saved in an SQLite database  
- Simple screen system (menu, user selection, mission screens)

## Technologies
- Python 3.12+
- pygame
- SQLite

## How to run
```bash
pip install pygame
python main.py
